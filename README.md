# Monster Hunter Endfield

为《明日方舟：终末地》提供《怪物猎人：世界／冰原》的连续动作、自动演示、独立展示武器和本地练习。通过 E Mod Loader 运行，支持 Windows x64、EML format 1 / Native ABI 1。

当前版本为 **`1.0.0-combat-rc2` 离线候选版**。原生回归、资源检查、网页及隔离 EML 宿主验证已有记录，**尚未进行游戏内验证**。

## 功能与覆盖

| 终末地装备类别 | 怪猎模式 |
| --- | --- |
| 单手剑 | 太刀、片手剑 |
| 双手剑 | 大剑 |
| 长柄武器 | 长枪，包含独立左手盾 |
| 手铳 | 轻弩 |
| 施术单元 | 弓，使用独立弓模型 |

- 六模式支持可重绑定操作、组合键、按住／松开、输入缓存、派生提示与手动接管；自动演示可选完整、基础或招牌序列，支持循环、暂停和慢放。
- 33 个角色有独立骨架、手指、体型和脚底配置；80 件普通装备和两把特殊模型分别记录适用模式。角色可借助独立展示模型使用六模式，普通装备按型号适配。
- 莱万汀太刀提供独立火刀和附属骨驱动；提夫罗斯弓提供弓、弦、拉弦手指和本地箭矢。两把特殊模型支持跨角色展示，分别限太刀和弓模式。
- 1185 个可加载身体动作槽、196 条 PCM 音源（188 条模式音源＋8 条特殊模型原声）。动作槽包含上下文、合成和明确标记的旧条目，槽数不等于招式数。
- 七页网页工坊包含角色／武器资料、动作与键位、网格参考、六份有声源猎人演示、试听和预设；游戏 HUD 支持教学、精简、摄影布局及位置编辑。
- 本地练习默认关闭，独立维护模拟 HP、资源、格挡／反击和箭弹。目标选择与镜头聚焦可配置，近战采用三维扫掠和源时间窗，远程按入射距离与遮挡判定。

本地练习不发送战斗数据，不修改真实伤害、奖励或存档。场景怪物只提供位置和模型包络参考；模型包络不代表原生伤害碰撞体或已知弱点。伤害采用本地基础值与源 MV 的教学归一化，未实现完整怪猎伤害公式。

## 安装与操作

**本仓库提供源码，不包含原版游戏资源、烘焙素材或可直接安装的 ZIP。** 当前开发环境中的候选包是本地构建产物，尚未作为 GitHub Release 发布。完整运行包需要自行准备匹配版本的本地素材并构建，见 [开发与构建](docs/DEVELOPMENT.md) 和 [素材重建](docs/RESOURCE_REBUILD.md)。

取得完整构建包后：

1. 将 `endfield.longsword.showcase-1.0.0-combat-rc2-win-x64.zip` 导入 E Mod Loader。
2. 打开模组设置页，选择怪猎模式与展示武器并保存；游戏角色在游戏中另行选择。
3. 升级前停止旧演示。模块 ID 保持 `endfield.longsword.showcase`，沿用 schema 2 配置迁移。

| 操作 | 默认键 |
| --- | --- |
| 开启／结束手动模式 | F8 |
| 开启／停止自动演示 | F9 |
| 退出 | Esc |
| 普通攻击；大剑／弓按住蓄力、松开释放 | 鼠标左键 |
| 副攻击／远程瞄准 | 鼠标右键 |
| 气刃／防御等模式专用动作 | 鼠标前侧键；3 键鼠标为滚轮按键 |
| 闪避／收纳 | 空格／E 或 Shift |
| 选择聚焦目标／镜头转向／切换目标 | Q／Ctrl／Tab |

各模式的完整操作以“动作与键位”页为准，可选已核对的官方 5 键／3 键鼠标物理预设并独立重绑定。键位预设、招式派生和本地控制时序分别记录来源。网页未连接时可编辑草稿、管理预设和查看本地已准备的参考资源；保存后才应用到宿主。

详细安装、操作、练习和退出说明见 [使用说明](docs/USER_GUIDE.md)。

## 验证状态

198 个角色×模式组合及 66 个特殊模型×角色组合已有实际网格离线检查；这不等于所有握持、穿插和最终观感通过。原生 shader／VFX、布料与链条、真实场景接地和障碍、动态换装／挂载、输入音画同步及 HUD 遮挡仍待游戏内验证。

登龙的部分飞行与下降使用展示控制；弓的横向箭群分布和逐箭原挂点未重放；音频的原混响、RTPC 和加权随机未完整模拟。具体证据和限制见 [战斗候选版记录](docs/implementation/combat-rc2.md) 与 [覆盖表](docs/ADAPTATION_COVERAGE.md)。
