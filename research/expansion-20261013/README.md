# 怪物猎人：终末地——扩展初查

此目录记录 2026-10-13 的离线初查，结论以当日资源与源码为范围；没有游戏内验收。后续进展见 [项目计划](../../docs/PROJECT_PLAN.md)。研究输入与生成产物仅本地保留。

## 总体判断

可以朝多武器模式扩展。建议采用共用输入/播放/地面/音频/本地练习核心，按怪猎武器提供不同动作与连招数据，自动读取终末地角色的主骨架绑定姿势，再以少量角色与展示武器配置处理差异。无需为每名角色复制完整动画系统；目前的女管理员硬限制是代码范围。

莱万汀火焰长刀与提弗洛斯弓都有独立武器预制体和自身骨架，可作为跨角色展示武器的候选。当前已验证离线结构与引用；跨角色实机渲染、完整火焰和拉弦尚未验证。

## 三项结果

### 怪猎素材

- 本机完整安装 `<MHW_ROOT>` 的 13 个 chunkG 包共 54,895,522,591 字节；头与压缩子块表可读。
- 原版各武器的内部资源尚未提取和逐类解码。现有太刀仍使用 Rise Style MOD，不因安装游戏而自动切换。
- 当前缺现成解包程序与 `oo2core_8_win64.dll`；可按 [MHWNoChunk 作者仓库](https://github.com/JodoZT/MHWNoChunk) 的选取提取路线取人体、武器模型/装配、LMT、动作配置和音频，合并补丁覆盖，避免全量展开约55GB。
- 现有 LMT/MOD3 工具仍可读取 MOD 数据。人体转换流程可复用；盾、鞘、变形部件、弓弦等需按武器处理。没有验证14类武器全部共用当前外观MOD骨架。
- 170/171 曲线确实包含较长数据，170还标记 NeedsParent。刀向异常不能简单归因为缺下劈动画。修复应先对照原版动作上下文与武器装配关系，再校正重定向，避免继续估计剑尖方向。

详见 [MHW_RESOURCES.md](MHW_RESOURCES.md)。

### 终末地通用适配

- 现有32位角色缓存均具备当前21主骨及一致的主骨祖先拓扑，均有双手指根和基础左右武器挂点。检查仅覆盖这32份离线数据；没有其余角色与所有辅助骨骼的完整认证。
- 体型和静止数值存在差异，不能套固定女管理员矩阵或仅按身高等比缩放。可以共用读取 bindpose、人体轴对齐和两段IK的算法，逐角色验收握持、脚步和衣物，例外保留配置。
- 骏卫同时带主角色及4套士兵骨架，同名主骨出现5遍。当前全模型“名字→Transform”收集方式需要改为主角色蒙皮与完整路径绑定，避免选错子骨架。
- 武器配置应按模型/形态指定握柄、安装矩阵、轴向、左右手及盾/鞘/弓弦，不按角色名称猜方向。
- 角色证据来源是2026-09-29既有同版资源缓存，初查没有对32位角色重提取或实机播放。特殊武器另从当日本机客户端复核。

详见 [ENDFIELD_ADAPTATION.md](ENDFIELD_ADAPTATION.md)。

详见 [SPECIAL_WEAPONS.md](SPECIAL_WEAPONS.md)。

## 初步类别对应

以下是扩展建议，不是已实现的适配，也不要求角色永久锁定这些模式。

| 终末地装备类别 | 怪猎模式建议 | 需要新增的展示内容 |
| --- | --- | --- |
| 单手剑 | 太刀＋片手剑 | 太刀鞘、片手盾；莱万汀刀身可作为太刀候选 |
| 双手剑 | 大剑 | 校准双手握柄与各型号剑轴 |
| 长柄武器 | 操虫棍 | 双手棍、虫与跳跃；长枪后续需要盾 |
| 手铳 | 轻弩 | 准备匹配的双手弩枪展示模型 |
| 施术单元 | 独立弓模式 | 不直接让浮游法器拉弓，可用提弗洛斯或怪猎弓 |

本地装备表没有通用弓类别：提弗洛斯装备类型仍是施术单元，弓是其技能展示资源。莱万汀属于单手剑。

## 实施顺序与基线

优先取得原版太刀与源装配证据，将猎人模型上的下劈先验证正确，再推广主骨架绑定和武器显示。随后加入片手/大剑，并用不同体型复验握持。火刀可先使用刀身与原生材质，再加入火焰；弓需保留武器自己的子骨架。

初查时旧 `profiles/`、`dist/` 和部分 `native/*.h` 缺失，历史 README 测试记录不足以确认当时的完整构建基线。此项是初查快照；后续修复与构建状态以项目计划和实施记录为准。
