# 历史基线审计

日期：2026-10-13。本文记录早期太刀工程扩展前的库存审计，**不代表 `1.0.0-combat-rc2` 的构建状态**。当前构建条件见 [开发与构建](DEVELOPMENT.md)，当前离线结果见 [战斗候选版记录](implementation/combat-rc2.md)。

## 早期库存与缺口

早期目录保留了 150 个有效 LSM 身体动作、21 主骨 `source_rig.json`、源骨架网页预览以及角色／武器研究材料。catalog 有 151 个条目，缺少 slot 1000 的组合登龙文件。LSM 的头、骨维度、FPS／帧数、文件长度和四元数约束检查通过；这只证明格式有效。

原工程缺少八个模块实现头、五个测试源、EML SDK／JSON 头、角色 profile、握持／地面／源武器轨道、命中与派生清单和音频。已有网页预览并不能替代实际运行动作文件；旧 README 的测试描述也不能证明当时库存完整。

## 后续处理

`0.6.0-dev` 重新实现了仍被模块调用的接口，补齐 SDK、测试和有来源的动作／配置／音频，并重新构建验证。该实现并非已删除历史文件的逐字节恢复，详见 [0.6.0 版本记录](implementation/0.6.0.md)。后续六模式工作进入 `offline-rc1` 和 `combat-rc2`。

审计保留的技术要求仍适用：运行数据要按实际读取契约验证，不能用空头文件、空 JSON 或删除缺失招式来获得假通过；源码构建、素材完整性、离线宿主及游戏内外观必须分别验证。机器清单和原始历史材料保存在本地，不随公开仓库分发。
