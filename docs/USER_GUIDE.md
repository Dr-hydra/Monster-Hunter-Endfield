# Monster Hunter Endfield 使用说明

本版是 `1.0.0-combat-rc2` 离线候选包：以源资源、离线动作/网格、网页和隔离 EML 宿主检查为交付范围，尚未进行游戏内验证。覆盖太刀、片手剑、大剑、长枪、轻弩、弓；33 个角色有独立配置，80 件装备和两把特殊武器有模型记录，包含 1185 个可加载身体动作槽及 196 条 PCM 音源。角色覆盖、静态网格检查和最终玩家观感是不同证据，网页分别显示。

## 安装与升级

源码仓库不提供原版游戏资源或完整安装 ZIP。当前候选 ZIP 是本地构建产物，尚未作为 GitHub Release 发布；需准备完整素材并按 [开发与构建](DEVELOPMENT.md) 生成包。

1. 在 E Mod Loader 中导入 `endfield.longsword.showcase-1.0.0-combat-rc2-win-x64.zip`。
2. 打开该模组的设置页，选择模式与展示武器，保存。安装包包括 Windows x64 原生模块、姿势/手指/武器轨道、提取后的 PCM 和网页资源。
3. 原模块 ID 仍为 `endfield.longsword.showcase`。升级前先停止旧演示；同 ID 导入应作为原条目的更新/替换处理，避免同时保留多个播放模块。

旧版太刀配置迁移至 schema 2，保留用户设置及按模式保存的 `mode_keys`。网页的未保存编辑、离线草稿、已保存等待宿主应用和宿主已应用分别显示。升级后如旧键位不顺手，在“动作与键位”中恢复当前模式默认并保存；不会自动清空预设。

本候选包针对研究记录中的客户端资料生成。客户端更新、新角色或新装备需要重建对应配置；不要把旧离线报告自动当作新版本通过。

该记录构建、回归、离线宿主及安装包检查结果见 [战斗候选版记录](implementation/combat-rc2.md)。

## 开始操作

| 操作 | 默认键 |
| --- | --- |
| 开启/结束当前手动模式 | F8 |
| 开启/停止自动演示，返回手动 | F9 |
| 退出演示 | Esc |
| 普通攻击；大剑/弓为按住蓄力、松开释放 | 鼠标左键 |
| 近战副攻击 | 鼠标右键 |
| 气刃/防御等近战独有动作 | 鼠标前侧键；3 键鼠标为滚轮按键 |
| 闪避 | 空格 |
| 普通收纳 | E 或 Shift |
| 弓/轻弩瞄准 | 鼠标右键 |
| 弓/轻弩独有动作 | 鼠标前侧键；3 键鼠标为滚轮按键 |
| 轻弩装填／弓装瓶按钮 | 鼠标后侧键；3 键鼠标为 R |
| 选择聚焦目标／镜头转向／切换目标 | Q／Ctrl／Tab，可重绑定 |

这两套物理键位已与怪猎官方 Steam 手册核对，动作与键位页可选 5 键鼠标、3 键鼠标或自定义。选择只替换当前模式，其他模式已保存键位保留；旧 Ctrl 和旧版键位不静默改写。所有模式以该页面和 HUD 当前可用派生为准，可捕获按键并按模式保存。Esc、F9、演示开关键保留给模组；Shift 为固定纳刀辅助。每招组合及本地控制器时序与物理键位分别验，依据和未知项见 [键位与操作核对](implementation/keyboard-controls.md)。

F9 会播放所选模式的连续演示。按攻击键可手动接管；网页也提供试演、暂停、继续和停止。未连接 EML 时执行按钮禁用，仍可浏览资源、编辑草稿与管理预设。查看角色资料不会替你切换游戏角色。

首页可选完整演武、基础连段或招牌招式，关闭“循环演示”后只播放一轮。序列与循环设置保存后应用；进度和秒数来自宿主当前演示状态，断开连接后清除。慢放使用“声音与表现”页的速度设置。

太刀常用组合：左键＋右键袈裟斩，独有动作键＋右键见切，独有动作键＋空格特殊纳刀，独有动作键＋左键登龙；特殊纳刀后左键居合、独有动作键居合气刃。独有键在 5 键鼠标预设为前侧键，3 键预设为滚轮按键，自定义以实际设置为准。特殊纳刀／见切的手动入口要求先攻击，网页试演和自动演示仍可编排。登龙源动作保留分阶段来源，部分飞行/下降是独立展示控制，未称为已复现怪猎原生战斗控制器。

其他模式的按住/释放、反击、冲锋和特殊招式从当前资源目录读取；没有直接键的招式可通过派生或网页试演。长柄对应长枪，盾为独立展示部件。

## 角色、装备与两个重点组合

先使用首页的“莱万汀太刀”或“提夫罗斯弓”入口载入编辑组合，随后保存。角色应在游戏中另行选择。两把特殊武器可作为独立模型跨角色使用，装配资料与运行验证状态按各条目显示。

“自动”展示武器按模式推荐模型；“源武器”使用怪猎源模型，片手/长枪附属盾也由展示系统管理；“当前装备”沿用角色装备。80 件原装备只有适用模式记录，不表示所有型号都适合六类动作。不成立的组合优先选独立模型，不强套原装备。弓模式使用独立弓，不把施术器当作弓。

角色与武器分别适配：共享主逻辑，角色保留自己的静止姿势、体型、手指、脚底和挂点配置。网页可查看每个角色×模式的离线状态和静态实际网格参考。源骨骼播放器展示怪猎源姿势；目标参考图不会随时间轴同步。

## 声音、表现与 HUD

声音由提取后的 WAV 走统一 PCM 链路，支持分组和主音量、试听、循环/取消/淡出。切页、静音、失焦和停止会清理试听或运行声音；发生缺音源/设备问题时页面显示原因。普通挥刀包含明确标记的终末地原声，其他源声音按目录来源查看。

莱万汀刀的火焰与提夫罗斯弓的拉弦/放箭另有 8 条终末地原声音源，已从有效资源提取，同样走 PCM。原刀的 16 秒火焰垫音由模组按展示生命周期重复；不把这个重复策略称为原技能无限循环。音源清单可试听各个原事件变体，游戏原混响、RTPC 和随机权重仍未模拟。

表现页可以调速度、混合、输入缓冲、显示位移、握持强度与特效档。位置变化是模型展示位移；接地、墙面/低顶限制使用可取得的场景查询，不能等同真实角色移动。实际场景效果尚待游戏运行验证。

HUD 提供教学、精简、摄影布局，尺寸、主题、准星及目标信息可独立调整。进入 HUD 编辑后拖动浮层，结束编辑后位置回到设置；只有布局变化会保存，不覆盖其他未保存编辑。失焦会隐藏浮层并清理操作。摄影布局适合截图，不显示完整教学提示。

## 本地练习

练习默认关闭。独立练习球整球为明确的模拟弱点；场景目标的 Renderer 包络不是原生伤害碰撞体，弱点状态未知。本地伤害采用基础教学值 × 源 MV / 100，未实现完整怪猎伤害公式。可选择独立练习目标，或把附近怪物的位置作为只读参考。模拟 HP、命中、格挡/反击反馈、招式资源和箭矢/弹体由本模组本地计算；不会新增真实伤害、奖励、结算或战斗发包。真实怪物仍按游戏原规则活动。

练习页可调整模拟 HP、基础模拟伤害和目标范围，重置该版本统计。资源值、等级、格挡反馈和弹体数量来自宿主实际报告。断开连接后当前目标/资源信息作废，既有统计标为该版本记录。

弓与轻弩的展示箭弹速度可在练习页设置为每秒 1–120 米；它只影响本地展示弹体，与真实弹药或伤害无关。

## 预设、诊断与退出

预设在当前浏览器本地保存，支持另存、载入和 JSON 导入/导出。载入只进入编辑区，保存才应用；无效/未来版本配置拒绝并保留当前编辑。多窗口同时改设置时，页面会说明宿主版本冲突，再决定是否覆盖。

问题排查先看“检查与帮助”：连接、当前模式、声音、地面约束和资源缺项会分别报告。诊断导出只含白名单状态，不含私人资源路径或素材。动态挂点、衣物、原生 shader/VFX、场景/镜头与实际声音时序留待后续运行检查。

停用或卸载前先按 Esc/网页停止，关闭使用模块的游戏和 EML 后，通过 EML 移除条目。停止会恢复姿势和原装备显示、销毁独立道具/HUD、停止 PCM 并清除模拟弹体；预设和草稿由浏览器单独保存，可自行导出留存。

动作与键位页另附六模式“源猎人＋武器 · 有声参考”：它是实际怪猎猎人和原武器的离线完整演示，声音依据统一 PCM 控制器时间轴预混为 65%，播放器音量可独立调节。点击才播放，离开页面、换模式或失焦暂停；它不代表终末地角色的最终效果。

莱万汀长刀当前只支持太刀，提夫罗斯弓只支持弓；不兼容的选项不显示，切模式会恢复自动展示武器。导入预设中的不兼容组合会给出错误并保留当前编辑。
