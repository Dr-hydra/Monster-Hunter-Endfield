# ADR 0001：项目边界与通用适配

日期：2026-10-13

状态：作为实施基线采用；武器最终映射和发布 ID 待用户确认。

## 背景

现有太刀项目已迁移至 `G:\Monster Hunter Endfield`，产品范围拟扩展到终末地五类装备。32 份缓存支持共用 21 主骨运动链，但存在体型、安装关系及重名子骨架差异。特殊刀/弓是独立资源，尚未验证跨角色实机表现。历史 `0.5.6-dev` 存在源码与数据缺项，须先恢复可构建基线。

## 决策

1. 沿用 Windows x64 C++ EML format 1 / ABI 1。本轮保留原模块 ID 与配置，不实现新功能。
2. 共用输入、动作、重定向、接地、音频和本地练习算法。角色 profile 管主骨架识别与体型例外；武器 profile 管资源/形态、安装矩阵、握柄和附属部件。挂点同名不等于安装变换相同。
3. 原版太刀来源、父级动作上下文和源武器装配验证先于多武器扩展。不再由预期剑尖朝向猜测手腕旋转。
4. 火刀与弓按独立视觉实例接入，保留其子骨架；不通过发动原角色技能获得模型。
5. 本地练习只维护独立 HP 和统计，不调用真实攻击、伤害、奖励或发送接口。演示位移限制在显示层；正常游戏通信不保证为零，新增调用须审查和本地验证。
6. 所有声音离线提取后进入统一 PCM 链路，不另触发游戏音频事件。Git 只提交源码、文档和配置模板；游戏/模组派生素材和大型输出留本机。

## 影响

可以以同一人体算法扩展角色，减少重复烘焙和条件分支；代价是每个模式仍须处理左右手、盾、鞘、弓弦等部件，并按体型实机验收。资源读取成功不能替代显示、动作或网络边界验证。

施术单元映射弓属于候选；完整 14 类武器、真实伤害和联网共演不包含在当前计划。后续按 [项目计划](../PROJECT_PLAN.md) 的 M0–M5 阶段推进。
