# ADR 0001：项目边界与通用适配

日期：2026-10-13；范围修订：2026-10-14。

状态：已采用。武器映射按 2026-10-14 用户决策更新，发布 ID 继续兼容现有模块。

## 背景

现有太刀项目已迁移至 `G:\Monster Hunter Endfield`，扩展到终末地五类装备、六个怪猎模式。32 份缓存支持共用 21 主骨运动链，但存在体型、安装关系及重名子骨架差异；噗切娜另需补图。特殊刀/弓是独立资源，尚未验证跨角色实机表现。历史 `0.5.6-dev` 缺项已在 `0.6.0-dev` 恢复，当前以其实施记录为基线。

## 决策

1. 沿用 Windows x64 C++ EML format 1 / ABI 1，保留原模块 ID 与配置；正式 ID 若迁移须提供转换与冲突处理。
2. 共用输入、动作、重定向、接地、音频和本地练习算法。角色 profile 管主骨架识别与体型例外；武器 profile 管资源/形态、安装矩阵、握柄和附属部件。挂点同名不等于安装变换相同。
3. 各模式先验证自身原版来源、父级动作上下文和源武器装配，再向全角色批量推广。莱万汀太刀与提夫罗斯弓可并行；不由预期剑尖朝向猜测手腕旋转。
4. 火刀与弓按独立视觉实例接入，保留其子骨架；不通过发动原角色技能获得模型。
5. 本地练习只维护独立 HP 和统计，不调用真实攻击、伤害、奖励或发送接口。演示位移限制在显示层；正常游戏通信不保证为零，新增调用须审查和本地验证。
6. 所有声音离线提取后进入统一 PCM 链路，不另触发游戏音频事件。Git 只提交源码、文档和配置模板；游戏/模组派生素材和大型输出留本机。
7. 长柄对应长枪，单手剑对应太刀/片手剑，双手剑对应大剑，手铳对应轻弩，施术单元采用独立弓展示。莱万汀太刀和提夫罗斯弓并列重点，最终跨角色通用；原装备不适用时用已验证独立模型。
8. 角色材料优先使用 BE 离线导出、带网格预览和批量验证；运行检查集中于动态挂载、原生渲染、场景和恢复等离线不能证明的环节。
9. 游戏 HUD 和外部网页纳入成品工作包，共用模式/配置状态；按信息层级、预览反馈、预设、可访问性和实际宿主联动验收。

## 影响

同一人体算法减少重复烘焙与分支，但每模式仍须处理左右手、盾、鞘和弦。全角色离线带网格检查与必要的运行抽验分别留证；资源读取成功不能替代显示、动作或通信边界验证。

弓已纳入主线，操虫棍优先的历史建议由长枪替代。完整 14 类武器、真实伤害和联网共演不包含在 1.0。按 [成品计划](../PROJECT_PLAN.md) M0–M6 推进至正式成品，以 [覆盖表](../ADAPTATION_COVERAGE.md) 和 [界面计划](../UI_DESIGN_PLAN.md) 验收。
