# 太刀动作演示

为女管理员（`chr_0003_endminf`）制作的怪物猎人风格太刀动作演示模块。使用独立输入与连招系统，读取已烘焙的骨骼动作，在游戏中叠加播放，支持提前输入、动作过渡、源动作位移、原武器保持显示和镜头跟随。0.4 增加可选本地怪物练习；命中、模拟血量和统计均由模组维护，不写游戏真实血量或调用战斗发包接口。

## 0.5.6 撤回剑向估计，按手掌骨架映射

0.5.5 把登龙末段的向下方向估计推广到全部 17 个动作，造成插地和普通动作方向回归。本版删除这个安装角度估计和运行时剑尖地面改向；不再为让剑尖朝下而旋转手腕或分配前臂转腕。

手腕静止姿态依据两边实际骨架的腕骨、中指、食指与小指根部绑定位置映射。源数据来自用户外观包的 MOD3，目标数据在运行时从女管理员蒙皮绑定矩阵读取；不使用当前游戏动作作为静止姿态。缺少指根绑定时保留基础手臂映射，并在状态中报告。装备保留实际模型到原生挂点的安装关系，方向随映射后的手掌运动。源 247 坐标只用于双手间距，不再被当作源剑身坐标。

151 份身体 LSM 与 0.5.5 包逐字节一致，登龙动作选择、腾空高度、303 帧时间轴和声音没有重新编排。17 个动作完成手掌坐标核对；运行时回归包含伪造向下源坐标不会改变原生剑向、双手指根绑定、重复帧、缺少指根时回退和退出恢复。

本版修正有明确数据依据的坐标回归；不声称完全还原怪猎登龙。原始怪猎武器装配矩阵仍缺失，原组合的动作上下文、补写飞行和计时继续是研究限制。离线图仍不等于游戏内效果；未验证手指、衣物碰撞。证据与复现命令见 `research/weapon-v056/README.md`。

## 0.5.5 连续源挂点与双手握持（历史实现，方向覆盖已由 0.5.6 撤回）

删除旧版分时段的竖劈方向关键帧，改为 17 个演示动作的每帧源 247 挂点旋转，贯穿登龙起手、空中下劈、落地与收势。换招按同一动作过渡时间混合完整握柄坐标和辅助手位置。源包没有怪猎武器装配数据，因此源安装旋转使用视频末段与源挂点的一次固定配准，明确属于估计；不声称精确恢复原版安装关系。

实际装备同时识别剑身长轴和宽轴，约束刀向与刀面，而不是只把一根方向向量转到竖直。主手校准先于辅助手 IK，辅助手跟随修正后的握柄坐标；转腕中的轴向旋转由前臂分担 65%，保持肘和腕的位置与手臂长度。修正坐标系在约 180° 翻转时可能反转宽轴的问题。

原组合存在单帧超过 100° 的旋转；新增中间姿势，保留原有姿势与最短转动路径，将身体和主挂点的每帧步长限制为 20°，同步插值脚底离地高度。登龙现在 303 帧、约 5.03 秒；地面、音效、练习窗口和骨架预览均随新时间轴更新。尚未游戏内验证刀柄安装、手指或衣物碰撞。离线双手/剑向证据见 `research/helmbreaker-v055/`，两包对比见 `research/helmbreaker-channel-audit/`。

## 0.5.4 宏愿剑向与原生挂点（历史实现，已由 0.5.5 替换）

针对用户实际装备的「宏愿」（`wpn_sword_0021`）提取只读原生模型证据。其剑身长轴在武器根节点 +Y，而非统一假设的 +Z；武器子网格有额外 -90° X 变换。运行时从细长网格的 Bounds、节点变换及相对握柄位置识别剑身轴和尖端，保留当前装备模型到原生握刀节点的偏移。

同步 `wep_R` 和独立的 `IK_Weapon_R_001`，并在可识别装备模型时同步其显示根节点。登龙增加明确编排的举刀—竖劈—收势方向轨道，校正主手腕后再驱动原生武器，避免人体与刀向各自变化。空中剑尖限位使用场景地面高度，不使用腾空脚底高度。未确认网格长轴时保留基础播放，并在网页武器状态显示「剑向待校准」。退出按写入所有权恢复位置与旋转；销毁或切换模型时停止写入旧对象。

这是视觉竖劈校正，不声称还原怪猎原始手腕/刀向曲线。离线验证已包含宏愿原生轴、女管理员骨架和剑尖轨迹；六组测试覆盖分离的武器节点、网格轴向/极性、重复帧、地面限位和退出恢复。未启动游戏，尚未验证实机握柄偏移、手指或衣物穿模。证据与前后对比见 `research/weapon-v054/README.md`。

## 0.5.3 视频参考与完整登龙曲线

按用户提供的《怪物猎人世界太刀登龙斩教学》约 1:08–1:11 训练场片段对照，并参考后面两轮实战。发现输入动作包中 170 的动作头长度为 32 帧，但其曲线延伸到第 106 帧；171 的动作头长度为 1 帧，但曲线延伸到第 46 帧。先前按头部范围导出，漏掉了实际抬刀、下劈和落地恢复。现在使用独立研究副本扩大取样边界，源 LMT 文件不修改。

登龙的空中准备和下劈统一来自完整 170:0..106，落地来自 171:0..46；不再借用 160 抬刀或只混合两帧代替完整挥刀。共 194 帧 / 60 FPS，约 3.22 秒。握刀、地面、网页预览、声音和模拟练习窗口同步重烘焙。飞行轨迹仍是本模组编排；真实屈腿姿势导致源脚底峰值约 3.53 米、女管理员离线约 3.05 米，不能当作怪猎官方高度的测量结果。

离线前后对比与限制见 `research/helmbreaker-v053/README.md`；用户视频关键帧及完整源曲线在 `research/helmbreaker-reference/`。尚未游戏内验证装备刀的朝向、握刀挂点或网格碰撞。

## 0.5.2 登龙姿势与高度

登龙改为截取源起跳素材后半段的抬刀姿势，避免上升途中提前挥刀；最高点保持高位抬刀，再接源 170 后半段的下劈收势。增加展示腾空幅度，调整快速下降与落地衔接，组合为 188 帧 / 60 FPS，约 3.12 秒。源高度由约 1.67 米增至 2.88 米；女管理员骨骼离线计算的脚底最大离地高度由约 1.43 米增至 2.49 米。这是编排值，并非测量得到的怪猎官方跳跃高度。

所有混合帧用旋转重算源骨骼位置，避免线性插值导致手臂缩短、脚底参考与实际旋转不一致。握刀、脚底、网页预览、下劈声音和本地练习窗口同步重烘焙。保留场景地面和低顶检查。

离线对比见 `research/helmbreaker-v052/female_admin_comparison.gif` 和 `validation.json`。未游戏内验证；原装备刀的朝向、网格碰撞和与怪猎原动作逐帧一致性仍需实机视频校准。

## 0.4 改进与本地练习

源骨架 T 姿势和女管理员 A 姿势约相差 48°。运行时现根据源/目标静止姿势对齐肩臂，并将前臂校正传递到手腕；此前只套用世界旋转差会偏移手与武器路径。17 个常用动作增加源双手间距轨道，仅在双手靠近时用左臂两段 IK 调整辅助握刀位置，保持骨长、右手和手腕朝向。网页可调校正强度，设为 0 关闭左手 IK，静止姿势对齐仍生效。

离线女管理员 FK 对比中，见切的近握刀片段平均目标间距误差约从 11.7 cm 降至 3.1 cm；登龙约从 12.9 cm 降至 0.5 cm。居合气刃斩的改善有限。这里测量的是骨骼与辅助握刀目标误差，**不是网格穿模率**；没有完成游戏内武器、身体网格及衣物验收。研究对比图见 `research/retarget/target_fk_comparison.png`。

网页启用“本地怪物练习 · 实验”并保存，再回游戏 F8/F9 开始。默认关闭；默认模拟血量 1000、基础伤害 100。每 0.15 秒读取游戏 `ObjectContainer.allEnemies`，记录 20 米内有效活体敌人的实例编号与位置。动作攻击时段内用随右腕运动的近似刀刃扫掠检测，每个目标每个攻击时段最多命中一次；多段动作使用独立时段。模拟血量归零只显示练习完成，怪物依然遵循真实游戏血量、AI、攻击、仇恨、死亡和掉落规则。

游戏窗口左上方显示本地命中次数与模拟伤害；此提示为独立 Windows 穿透鼠标窗口，不接入游戏 HUD 或战斗通知。网页显示最多 12 个目标的模拟血量，并可重置。结束时移除目标引用并保留本轮统计，重新开始、重新启用练习或手动重置后重置；换人会结束本轮并保留最后记录。提示窗口在失焦、退出、停用时隐藏，卸载时结束线程；独占全屏模式下提示是否可见仍需验证。

刀刃轴、固定刀长、怪物球形范围与命中时段均为近似配置，尚无实机校准；接口不可用时提示原因，动作继续播放。不会暂停怪物攻击，也不会增加无敌或改变真实伤害。读取本地服务端证据见 `research/local-practice/README.md`：其 `CS_BATTLE_OP` 路径会接收并同步生命/死亡结果，本模块不进入该路径，也不拦截游戏原有网络流量。尚未进行实机抓包，不能把静态检查表述为“整个游戏零通信”。

## 使用

1. 在 E Mod Loader 导入 `dist/endfield.longsword.showcase-0.5.5-dev-win-x64.zip`，启用模块。
2. 在游戏中切换到女管理员，按 **F9** 自动演示连段，无需先记住键位；也可按 **F8** 开始手动演示。

## 配置与网页

默认启用模块；播放速度 1 倍、过渡 0.12 秒、输入缓冲 0.3 秒，启用源动作位移与武器保持显示。参数保存在 E Mod Loader 的模块配置中。首版角色配置固定为女管理员；后续角色可以共用输入和动作系统，但需要各自检查骨骼比例、手腕方向与握刀位置。

`show_prop` 控制“保持武器显示”：演示开始时申请游戏武器的 `Perform / InFight` 状态句柄，结束时只释放自身句柄，用于避免静止时自动收起武器。游戏已有 Perform 状态或相关接口不可用时，回退到无碰撞线条演示刀。备用刀的握刀偏移、朝向和刀长配置位于 `profiles/female_admin.json`。原武器挂点与动作仍待实机校准。

水平位移施加在显示模型根节点，髋骨保留垂直动作，镜头随水平位移与部分起跳高度跟随。逐帧恢复再应用覆盖，结束演示后恢复模组仍拥有的模型、骨骼与镜头位置。该显示位移不写实体战斗或导航位置。接口不可用时回退到骨骼层位移。

已加入用户提供的怪猎太刀音效包中 11 个片段，按参考表配到气刃、见切、特殊纳刀、居合与登龙，共 13 个动作时间点。默认开启，音量 65%；可在模块网页关闭或调节音量，并试听见切、居合与登龙。

声音随动作开始、时间推进和重播触发；连招中可重叠，静止纳刀不会反复播放。关闭演示、失焦、换人、停用或关闭音效时停止播放。声音不可用时动作仍继续。见切成功声是展示提示，没有命中、伤害或成功判定。该包没有提供可确认对应普通斩与翻滚的音效，因此这些动作暂不另配声音。

音效使用独立的 Windows 音频输出，音量由模块设置控制。参照 BE 的 PCM 调度和软件音量处理，保留游戏自身声音；音效不进入游戏的 Wwise 混音与空间定位。解码 WAV 没有烘焙原 bank 的容器/RTPC 音量。招式标签依据用户提供的 2020/7/13 对照表，音效时间点由本模组编排，仍需游戏内校准。

直接打开 `ui/index.html` 也能查看设置与离线源骨骼预览。在完整包中预览数据嵌入 `ui/preview-data.js`，无需网络或 CDN；开发目录如受到 `file://` 读取限制，可手动选择 `assets/ui_preview.json`。离线网页按钮不会驱动游戏。

模块消息：`{ "action": "toggle" }`、`demo`、`stop`、`status`；动作请求为 `{ "action": "command", "name": "slash" }`，可用名称见网页；资源检查为 `{ "action": "preview", "slot": 1 }`。状态可返回 `runtime_ready`、`active`、`slot`、`character`、`detail`、`phase`、`auto_demo` 、`demo_step`、`demo_seconds`、`weapon_mode`、`sound_ready`、`sound_enabled` 与 `sound_detail`。

## 构建与打包

使用 Visual Studio C++ x64 工具与 CMake，构建项目后原生库应位于 `build/package/native/windows-x64/endfield.longsword.showcase.dll`。原生构建命令以根 `CMakeLists.txt` 的设置为准。

```powershell
cmake -S . -B build -A x64
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
python tools/package.py
```

音效资源可通过 `python tools/bake_audio.py` 从本地已解码候选目录重新收集，无需重新下载。

打包脚本从 `build/package` 收集 DLL，从项目目录收集清单、网页、烘焙动作、角色适配 `profiles/*.json` 、`assets/audio/*.wav` 与音效时间表及说明，输出 ZIP 根目录直接包含 `module.json`。缺少必需的 `profiles/female_admin.json` 时打包失败。可通过 `--package-root` 指定原生库包目录。不收集研究目录、原始 `.lmt` / `.mod3`、源码、构建日志或产物哈希。
