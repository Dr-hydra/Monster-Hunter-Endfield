# 六模式武器工坊与本地 HUD

实施日期：2026-10-14。本文记录网页与浮层实现，未启动游戏或服务端。

## 网页

`ui/index.html`、`app.js`、`style.css` 和 `workshop.js` 提供七个设置页面：开始、角色与武器、动作与键位、声音与表现、本地练习、预设、检查与帮助。六个模式为太刀、片手剑、大剑、长枪、轻弩、弓。33 个角色内置为资料回退列表；实际可用状态来自构建目录和宿主能力，不根据计划资料自动升级为通过。

莱万汀太刀与提夫罗斯弓为首页推荐，可将组合载入编辑区。查看角色不会切换游戏角色。角色 × 模式逐项展示离线动作、宿主与运行证据；通用骨架资料不能扩写为全模式已验证。

使用 `betterEndfield` 原桥接的 `status/readConfig/saveConfig/send/onmessage`。运行状态来自原生模块；提交意图与动作真正执行分开。请求带 `request_id`，宿主未及时回报显示可重试原因。默认停止入口常驻，未连接时禁止游戏执行按钮但保留离线浏览、试听和草稿。

配置版本为 2，保留旧太刀字段并迁移。编辑未保存、离线草稿、已保存等待应用、宿主已应用、保存或应用失败分别显示。浏览器草稿在连接后明确待用户载入，不覆盖宿主；保存前重读宿主检测多窗口冲突。HUD 拖动只合并布局锚点并通过既有保存桥接持久化，不将未保存设置偷偷送入游戏。

模式键位有 VK 编辑、捕获、内部冲突提示与模式作用域；Esc 保留退出。捕获弹层内 Esc 只取消编辑。模组默认用左键攻击、右键副攻击、Ctrl 特殊动作、空格闪避、E 收纳；远程以右键瞄准、侧键 1 副攻击、R 装填区分输入。模式目录的 `default_bindings.keys` 始终生效，`verified` 只表示是否取得怪猎官方默认键位依据，不阻止模组可用的键位生效。已有 `mode_keys` 保留用户设置。精确游戏默认尚未核对，页面明确标为模组映射。

预设保存于独立浏览器库，支持另存、载入、删除、JSON 导入导出。覆盖同名或删除才确认；新版本、非法范围、危险字段名、无效按键及超过 64 KB 的预设拒绝并保留当前编辑。诊断导出有明确字段白名单，不含私人路径、账号、凭据或游戏素材。

## 声音与预览

试听校验 PCM WAV，支持单/双声道和 8/16/24/32 位 PCM/32 位浮点；线性转为 48 kHz 双声道、整数采样量化、RMS 0.18 / 峰值 0.92 / 最大 3 倍音量平衡，然后乘 cue 增益、声音分组和主音量。算法与 `native/audio.h` 一致，使用 WebAudio Buffer，未调用游戏声音事件。切页、静音、失焦、停止及页面退出清理播放；缺文件或设备错误给出明确状态。

源骨骼预览提供前/后/侧/斜侧、暂停、逐帧、拖帧、速度和本地 JSON 导入。不同模式缺预览时显示缺项，不能借太刀动作代替。源骨骼、目标网格和实际运行的验证层级明确区分；烘焙完整角色网格预览应由素材流水线另供。

## 原生 HUD

`native/practice_hud.h` 保留 `Update(bool,string)`，扩展 `Update(HudSnapshot,HudSettings)` 和 `TakeLayoutEdit(float&,float&)`。原生模块填入同一运行状态，浮层只显示，不重新计算连招或命中。

HUD 显示模式、手动/自动/暂停、当前招式、退出键、编排章节、真实已实现的本地资源、派生键、模拟目标 HP 和命中统计。弓/轻弩仅实际瞄准时显示独立穿透准星与蓄力环。布局支持教学、精简、摄影、75%–200% 缩放、归一化锚点、安全边距与主题。摄影隐藏；编辑摄影布局时仍能显示拖动面板。

位置以宿主游戏客户区和 DPI 计算，夹取于可见客户区，不沿用窗口外框固定偏移。运行时点击穿透，编辑时只接受拖动且不激活窗口；松手交回归一化锚点。失焦隐藏并释放捕获，结束和卸载销毁面板、准星、字体、GDI 资源并加入线程。Win32 同步重入使用递归锁避免释放鼠标捕获死锁。状态不变时不重复重绘。

## 验证与边界

`node tools/ui_verify_rules.cjs` 通过：六模式、33 角色、迁移、非法导入/键位、PCM 采样与平衡已知结果。真实 Edge + Playwright CLI 完成 **54 项** 检查：推荐组合、全部七页导航、预设覆盖/取消、旧版导入/未来版本拒绝、捕获 Esc、冲突/复位、390/768/1365/1920 宽度的全部页面无文档溢出、200% 等效 CSS 视口、高对比文字 ≥4.5:1 / 控件边框 ≥3:1、模拟宿主的演示/暂停/停止/保存应用/保存失败/断连，以及本地 WAV 试听和停止。

复现：启动根目录只读 HTTP 服务到 `127.0.0.1:8877`，以 Playwright CLI 加载网页，然后 `run-code --filename tools/ui_browser_verify.cjs`。该脚本只为独立浏览器注入显式 `?mock=1` 测试桥接；生产页面不包含测试宿主。证据在 `output/playwright/workshop-browser-verification.txt` 与三张 `workshop-*.png`。

`tests/hud_tests.cpp` 提供客户区/DPI/宽屏/小屏/无效配置布局、窗口生命周期、点击穿透、无焦点编辑、鼠标拖动释放和 GDI 计数检查。窗口创建通过 `WaitUntilReady` 的真实初始化事件等待，不根据首个窗口句柄或固定延时误判准星已经创建；半初始化失败也销毁已创建的另一窗口。立即 Stop 的初始化竞争也纳入回归，修正后 HUD 连续 30 次执行通过。

最终产品目录通过 `tools/build_product_catalog.py` 从当前六模式、33 个角色配置和 82 个武器模型记录生成；包含 188 条 PCM、104 份实际源姿势预览、198 个角色×模式网格参考入口及 210 张视角参考图。太刀也优先读取最新 per-mode 预览，旧根目录缓存仅作明确回退。网页目标图是静态真实蒙皮参考，不冒充随源动作同步的完整目标播放器；198 个入口不表示视觉质量已经认证。

本地练习页显示宿主报告的资源值、等级、格挡反馈和展示弹体数量；失去连接立即作废当前资源读数。所有这些数据是独立本地状态，没有真实 HP 或服务端资源写入。

打包器检查六模式动作/音效/手指/地面/源武器轨道、命令/按住/松开引用、33 个角色、80 件装备及两把特殊武器、PNG/RGBA 纹理和全部网页参考图依赖。`--validate-only` 可先检查而不生成 ZIP。派生的 `assets/build_provenance.json` 记录版本、来源、坐标约定和未决项；研究路径是证据标识，原始解包研究不复制进安装包。源码 `ui/preview-data.js` 只是小型兼容入口，打包时在 ZIP 副本内嵌完整离线目录与预览。浏览器本地文件可浏览内嵌目录，PCM 试听需 EML 或只读 HTTP 环境。

这些结果不等于实机通过。EML OfflineHost 和最终安装包由主模块整合验收；当前遵从用户要求不进行游戏实机验证。原生材质、实际场景遮挡、真实键位占用及玩家观感仍需后续实际运行检查。

最终动作页新增六份完整怪猎源猎人＋原武器的有声 MP4 参考，清单为 `assets/previews/source-tours/index.json`。实际 native PCM/time-line/fade 混音后与真实源网格帧编码，预混总量为 65%；播放器音量独立，不再次乘以默认 65%。默认暂停、`preload=none`、显式点击才播放，换页/换模式/失焦暂停。SOURCE REFERENCE 标签和说明明确它不是终末地角色实机效果。`tools/ui_source_tours_verify.cjs` 在真实 Edge 通过 49 项：全部六份媒体解码和播放/停止、作用域文字、无自动预加载、页面清理，以及特殊模型模式/非法预设校验。原产品 UI 回归 58 项仍通过。

离线候选版补入完整/基础/招牌演示序列、单次或循环，以及直接使用 `demo_progress` / `demo_elapsed` 的进度显示；没有连接或已断开时进度无效。网页与原生均迁移旧 `laevatain_blade=false` 配置为当前装备；专属刀仅适用太刀，专属弓仅适用弓。已有原生 `projectile_speed` 也提供明确本地箭弹速度控件，HUD 边距范围和未知音量组校验与原生一致。

最终新增 8 条特殊模型声音，来源为当前 Endfield VFS 的实际事件/HIRC/Media 分支。火焰归属 fire 音量组，弓拉弦归属 charge，放箭归属 weapon；网页和包验证使用实际源 WAV，同样做 PCM 解码和生命周期引用检查。莱万汀 16 秒垫音的重复明确为模组展示策略，原游戏混响/RTPC/权重不声称已模拟。

`workshop-ui-gate-browser.txt` 记录 61 项实际浏览器检查，`workshop-ui-gate-catalog.txt` 记录 280 项生产资源检查（104 源预览、196 PCM、198 网格组合），`workshop-final-controls.txt` 记录 43 项序列/循环/本地弹速保存及全部 8 条特殊音源实际试听。6 项 package 负向/闭包单测通过。最终 ZIP 的浏览器和 EML 导入另行记录，不以工作目录检查代替安装包检查。

后续已通过官方语言／地区入口读取《世界／冰原》 Steam 手册真实键位图片，新增 `mouse5`、`mouse3` 两物理预设与 `custom`。115 项实际 Edge 检查覆盖六模式两预设逐有效键、保存、无重叠和旧版／按模式设置保留；完整七页 UI 回归同步重新执行。预设选择只修改当前模式，手动改键转为 custom，远程隐藏未采集的 SpiritBit 并提供独立装填／装瓶键。官方物理对照、Hunter's Notes 招式条件和未解 GUI 组合图标分别记录，见 [键位核对](keyboard-controls.md)。

打包器另核对两刀×33 角色×20 核心槽的接触 mask 帧率／长度／binary pass／有限权重／区间，正权重不得越过实际几何通过帧；片手 10011／10112 的源手撑地与独立目标碰撞 guard，以及大潘 30 个实际蒙皮手 probe 也入闭包。9 项 package 负向测试覆盖错误权重、帧率、伪作者认证、撑地 contact／kind／尺寸、硬件条件路由及 hold variants，未将这些几何修正称为实机通过。新大剑三保持段加入后，实际源预览为 106 条；最终 production 目录浏览器为 279 项，输入行变化来自远程去未采集 SpiritBit 与弓装瓶按钮独立显示。

Laevatain 专属刀仅太刀、Typhoea 专属弓仅弓：页面候选项、配置/预设检查、切模式自动回退与 native Configure 一致。打包器进一步核对六份视频且仅允许声明引用的 MP4、全部源二进制的有限值/单位四元数/自身蒙皮仿射矩阵、cue 淡入淡出/增益/优先级和源挂点帧；资源原始路径仅作证据标识。
