# 1.6.3 rc2 缺口处理

当前开发版本 `1.0.0-compat-1.6.3-rc2`。基于 rc1 公开适配，继续处理运行时及资源工具审查发现。尚未进行游戏内验证；本记录只描述公开构建。

## 运行时修复

- 特殊独立模型的 `get_localBounds/set_localBounds` 改为在 `UnityEngine.Renderer` 上解析；严格测试校验声明类型、参数和返回值。它是历史声明错误，不是 1.6.3 才移动的方法。
- 模块 bootstrap 原生线程在执行托管解析/分配前注册 IL2CPP；借用已有注册时不擅自释放，自行注册时在成功、失败和异常退出时释放。
- 禁用后立即启用接受“等待上一轮主线程清理”的状态，旧姿势恢复及 lease 释放后再读取新素材、恢复输入。不会在 worker 强行清理 Unity 对象。
- 新生命周期测试调用真实模块入口和记录的 Tail/Input 回调指针，覆盖重试、快速切换、取消等待和延迟读取失败；仍不等于实机并发/GC验收。

## 弹体与资源工具

- 逻辑和显示弹体统一为最多 128 个槽，模型按需创建。整组模型及初始位置、可见性准备成功后才消耗发射资源；模型失效时先移除逻辑弹体，再执行碰撞，避免没有显示却仍命中。
- 完整包拒绝未检查、失败和带错误的角色/模式审核；两把特殊模型也要求当前全角色覆盖。参考图存在不能替代通过状态和当前输入证明。
- 审核证明直接记录角色数值配置、计算依赖和输入文件身份，打包重新核对。没有用产物哈希；路径、长度和修改时间的文件身份并非防篡改认证。
- solver/oracle 二进制必须不早于其源码输入；oracle 另外使用当前生成器在临时目录重生，逐字节比较成功后才保存独立来源记录。之后源轨道、rig、实际读取的 profile 值、生成器或 oracle 文件改变都会要求重新核验，避免给旧姿势贴上新输入证明。
- 角色资料先在 staging 完成整批生成与校验，再发布；可捕获的发布失败恢复旧文件。它不保证进程突然终止时跨多个目录的文件系统原子性。
- 产品目录的参考图、预览、provenance、product 和 audio JSON 同批发布，末尾失败会回滚整批；故障注入已验证旧字节保留。
- 完整审核快照保存在包内目录，运行时状态只加载界面需要的目录字段。真实 EML 离线验收曾发现完整快照令回包超过 1 MiB；已在载入时移除审核专用字段，并新增真实模块消息入口的无素材大小限制回归，防止状态/目录请求被宿主拒绝。
- 纹理以完整资源相对路径区分同名文件，重新解码时同步更新 PNG、RGBA 与元数据，避免新尺寸配旧像素。
- 首次发布不依赖旧 `assets/catalog.json`，发布计算使用烘焙输入副本。旧 Legacy 条目只有明确请求保留且实际文件存在时才接入，不再反写烘焙输入或默默延续旧条目。

工具预检、固定来源及补丁见 [资源工具链](../RESOURCE_TOOLCHAIN.md)。已有真实烘焙输入的隔离首发验证不等于在新机器上从两款原游戏完成全部素材重建。

## 构建与验证入口

公开源码新增 `tools/check_source.ps1` 及 Windows GitHub Actions，执行公开 DLL 构建、CTest `source` 标签的无素材回归、合成 Python 回归、两组网页规则检查。Python 测试依赖固定在 `requirements-dev.txt`；无需 npm 构建。

完整素材测试标记为 `local-assets`，与干净检出的源码检查分开。无素材绿灯不表示素材包合格，素材包合格也不表示游戏内效果通过。

完整运行包的本地输入与工具条件见 [素材重建](../RESOURCE_REBUILD.md)。

## 本轮离线结果

- 公开生产构建 CTest 29/29；独立无素材源码副本的 source 标签 22/22。这些覆盖本轮模块回调、线程注册、弹体和现有公开回归。
- 最终公开 Python 回归在独立无素材副本及隔离环境中 69/69 通过，包括失败网格门禁、来源漂移、生成事务、纹理更新和工具预检。
- 当前 34 角色×6 模式共 204 个普通组合，以及 34 角色×2 特殊模型共 68 个组合全部完成，零数值检查错误。合并前逐行验证当前输入合同；P0 为全部核心帧，其余为 stride 12 加片段边界。
- 当前生成器独立重生的 204 对 oracle（408 个 JSON/LTP 文件）与本次网格审核所用输入逐字节相同。该检查未替换已审核数据，也未计算哈希。
- 使用现有真实 bake 的隔离首次发布生成 155 clips、无 Legacy 条目，344 个 bake 输入文件逐字节保持不变；它不覆盖从原游戏起步的全新烘焙。
- 六模式各 30 分钟虚拟时间及 24 次素材切换的离线长跑通过。游戏内渲染、布料、GC、VFX、性能及实际操作效果仍需后续实测。
