# 0.6.0-dev 实施与验证

日期：2026-10-13。历史版本的离线实现与验证记录，未进行游戏内验证；当前版本见 [combat-rc2](combat-rc2.md)。

## 本版实现

重新实现八个被模块调用的接口，补齐 SDK／JSON 单头、测试和有来源的关联动作数据；该实现不是历史文件的逐字节恢复。Windows x64 DLL 可从当前源码编译，模块 ID 与 ABI 保留。人体重定向以主 SMR 的 21 骨 palette 与完整路径/唯一主骨架识别，避开分身与士兵子骨架；从实际绑定姿势读比例。

保留女管理员，新增重点适配莱万汀及独立 `wpn_misc_0016` 刀身。保留自身骨架和 bindpose，共享只读 mesh/material；以 Dispose 释放异步资源句柄。不实例化技能脚本；原装备全部隐藏成功后才显示独立刀，失败回滚，退出/换人恢复。

修复装配关系被每帧原游戏动画污染、换父对象后不重新采样、无剑轴识别时不更新挂点、部分恢复与显隐失败。角色实体未变但 ModelGo 被池化替换时也退出，避免继续接管旧骨架。首次近手运行时采样仍不等于已确认 authored 安装；莱万汀在 `wep_R` 的安装为实验，完整火焰、环和链尚未接入。

从完整 MHW 按补丁覆盖定向提取，发布 154 个原版动作、4 个 Legacy 保留条目和一个 392 帧实验登龙组合。170 不是完整登龙；组合使用 170 起手、171 上升、172 空中攻击和 173 落地。源手腕不加刀尖朝下旋转；原生下降逻辑未完整解出，展示控制明确记录在元数据。

声音共 25 个 PCM 音源：22 个怪猎原声，加从当前终末地 VFS 核验并提取的 3 个普通挥刀变体。统一开关、音量、重叠与停止。演示补全第三普通斩和每组第五气刃，避免只有第一段动作/声音。

本地练习维护独立模拟 HP、命中去重和统计。真实怪物仅作为读取目标；没有增加真实攻击、伤害、技能或战斗发送调用。该版本未做通信抓包，代码审查不代表整个游戏零通信。

## 验证

九项测试覆盖连招、实际模块恢复、PCM、重定向、模拟练习、刀轴、主骨架、独立刀生命周期及真实资源初始化。资源测试运行两轮实际 F9 调度，要求五段气刃、见切、纳刀、两种居合和登龙均出现，并验证三种普通斩、起跳和下劈的不同声音确实触发。

最终构建九项测试全部通过；实际素材初始化加载 159 槽、27 个握持轨道、159 个地面轨道和 25 个 PCM，两轮自动演示覆盖 17 个动作槽位及 17 种声音。

Playwright CLI 在真实 Edge 验证 17 槽源预览（1000 为 392 帧）、长刀开关/音量保存重载、四段 WAV 播放及静音停止；1365 与 390 像素均无横向溢出。唯一已有控制台错误为本地 favicon.ico 的 404，无功能请求失败。截图/日志留本地 `output/` 与 `.playwright-cli/`。

配置页还通过模拟宿主回调验证莱万汀角色/长刀状态、1000 登龙显示、长刀设置保存，以及 demo/stop 请求。此 UI 回调验证与后述真实 EML 导入是不同层次。

EML 包以真实 ModuleStore 隔离导入及 OfflineHost 验证，结果见 [EML 验证记录](eml-verification.md)。用户正式模组库不修改。
