# 1.0.0-combat-rc2 离线验证记录

日期：2026-10-14。版本 `1.0.0-combat-rc2`；Windows x64，EML format 1 / ABI 1。公开模块独立运行，战斗练习不发送战斗数据，只维护本地模拟 HP／资源。未进行游戏内验证。本地构建 ZIP 尚未作为 GitHub Release 发布。

## 实现与操作

在六模式、33 角色、80 普通装备、两把特殊模型、1185 动作槽和 196 PCM 的离线基础上，加入目标选择、Focus／Target Camera、对象代次与生命周期、三维扫掠、部位／重复接触约束，以及远程首次入射距离与遮挡检查。长枪反击、大剑真蓄力、片手精准输入和弓档位箭群接入来源规则。

F8 进入／结束手动模式，F9 自动演示，Esc 退出。Q 选择聚焦状态，Ctrl 镜头转向，Tab 循环目标；镜头键可重绑定，与招式冲突时招式优先。镜头聚焦不自动把近战改成追踪攻击。

“命中”表示本地扫掠与目标包络相交，并通过时间窗、部位、去重和遮挡检查。场景目标的 Renderer bounds 或回退球不是原生伤害碰撞体，也不证明弱点或肉质。独立练习球整球为明确的模拟弱点；场景怪物包络保持弱点未知。

## 本地控制限制

片手精准资格在原始按键边沿冻结，等待缓存不会升级；末段命中后才接刺入与脱离。真蓄力首击按实际接触时刻获取明确模拟弱点资格，末击处理后不接受迟到首击。

弓按发射档位快照一次扣费，每箭独立接触编号；按源半径、速度与剩余射程截断。当前各箭方向相同，横向箭群分布、逐箭挂点和完整箭弹物理未重放。自动演示撤销手动箭弹和延迟链，不改变模拟 HP；单动作预览不消费战斗资格。

本地基础教学伤害 × 源 MV / 100，配合已实现的分支和刃色倍率，不构成完整怪猎攻击力、肉质、斩味、会心、技能、元素、异常及部位结算。登龙部分飞行／下降为展示控制，迟发接触锚点也非原骨挂点。

## 离线验证

原生全量 22 项回归通过；片手 bank 3 来源修正后的 5 项受影响回归再次通过，覆盖真实模拟接触、伤害、命中派生和完成动作。发行门禁 19 项负向测试通过。六模式各 30 虚拟分钟及 24 次加载检查通过，离线 PrivateUsage 采样增量均为 0；该结果只覆盖离线 CPU 与资产状态。

来源检查重新读取 6 份原 LMT／TIML、11 份 COL、283 条窗口、282 条 Move、428 个 w03p 字段及另 2115 个武器参数字段，并核对延迟节点和控制器来源。详情见 [控制来源核证](combat-source-closure.md)。

真实 EML 隔离导入及 OfflineHost 验证包含：旧版升级保留配置、六模式和 PCM、非法模式回滚、未就绪返回、停用／重装／移除及宿主退出。发行网页资源检查 116 项、控制检查 36 项分别完成；方法见 [EML 验证](eml-verification.md)。原始日志与报告保存在本地忽略目录，不包含在公开源码中。
