# 世界／冰原 PC 键位与动作操作核对

本版区分**物理默认键位、招式身份、派生条件、模组时序**四层。官方物理键位表已核对；它不能自动证明每个派生或本地状态机与原游戏完全一致。

## 官方来源与抓取

- [Steam 基础键盘控制](https://game.capcom.com/manual/MHW_PC/en/steam/page/2/2)：按键图片和动作说明。
- [Steam 基础手柄控制](https://game.capcom.com/manual/MHW_PC/en/steam/page/2/1)：逻辑按钮与近／远程动作对照。
- [默认键盘预设说明](https://game.capcom.com/manual/MHW_PC/en/steam/page/19/1)：默认配置按鼠标按钮数量区分，可按类别保存自定义预设。
- [近战武器](https://game.capcom.com/manual/MHW_PC/en/steam/page/8/1)与[远程武器](https://game.capcom.com/manual/MHW_PC/en/steam/page/9/1)：官方要求详细操作参考游戏 Hunter's Notes，这两页本身并非完整招式键位表。

需先在官方手册入口选择 English 与地区。此轮使用不含年龄输入的 United Kingdom 地区；普通地区表单提交后页面正常可读，无需启动游戏。可重建抓取：`python tools/mhw_fetch_keyboard_manual.py`。实际 HTML、图片文件名与段落、URL 清单在 `research/keyboard-defaults/`，真实 Edge 全页截图为 `output/playwright/mhw-official-pc-keyboard.png`。

官方页面按鼠标按钮数量说明，未提供这里可证的“Type 1＝五键／Type 2＝三键”关系。本模组使用明确的 `mouse5`、`mouse3` 标识，避免混淆选项中的其他 Type 编号。

## 已核对的物理映射

| 动作 | 5 键鼠标默认 | 3 键鼠标默认 |
| --- | --- | --- |
| 近战普通攻击 | 左键 | 左键 |
| 近战副攻击 | 右键 | 右键 |
| 近战防御／武器独有动作 | 前侧键 | 滚轮按键 |
| 远程射击 | 左键 | 左键 |
| 远程瞄准 | 按住右键 | 按住右键 |
| 远程武器独有动作 | 前侧键 | 滚轮按键 |
| 轻弩装填／弓装瓶 | 后侧键 | R |
| 回避 | 空格配合方向 | 空格配合方向 |
| 纳刀 | E 或 Shift | E 或 Shift |

Windows 标准虚拟键分别为前侧键 6（XButton2）、后侧键 5（XButton1）、滚轮按键 4（Middle Button）。鼠标驱动重新映射时按实际捕获值保存。原游戏 E 在拔刀时包含用道具语义；本模组这里只执行展示纳刀。

`tools/data/mhw_keyboard_presets.json` 保存两套原始对照；`mhw_keyboard_presets.py` 与 `mhw_finalize_modes.py` 发布至各模式默认元数据。`verified=true` 的范围仅为物理键位表，`weapon_specific_combinations_fully_verified` 保持独立。

网页选择预设只替换当前模式，其他模式已保存映射保留。手动修改按键会转为 `custom`；旧版 `keys`／`mode_keys`／`spirit_key` 保留原值，不静默改为新官方默认。远程不采集未使用的 SpiritBit，避免与 secondary 的独有动作键重叠。Shift 仅在未被自定义动作键占用时辅助展示纳刀；F8／F9／Esc 为模组控制。

## Hunter's Notes 与动作证据

有效原版 `common/text/weaponTutorial_eng.gmd` 与中文对应文件已定向提取，无需启动游戏；解码器 `tools/mhw_decode_control_text.py` 严格核对当前 GMD v0x10302 的 32 字节标签项、64 位标签偏移、文本数量与 UTF-8。原笔记、逻辑图标标签及六模式事实在 `research/keyboard-defaults/decoded-text/six-weapon-control-facts.json`。`steam/ot_weapon_*.gmd` 实为随从武器名录，已排除。

逻辑按钮必须按类别映射：近战 PAD_RU 为左键、PAD_RR 为右键、R2 为独有动作；远程 R2 为左键射击、PAD_RU 为装填／装瓶、PAD_RR 为独有动作，L2 为右键瞄准。不能把轻弩“按住 PAD_RU 全部装填”误写成按住左键。

这些更正保留源身体、手腕与武器轨道，只改操作关联和有证条件。招式命名依实际 COL 与 GMD，未验证字段、GUI 外填组合图标和原生控制器逻辑保留未知。

大剑保持段另有独立原资源佐证：`wp00_tree.at` 三组实际引用为 `[115,144,114]`、`[123,145,122]`、`[246,245,247]`。144 对应基础释放 152–154，145 对应强蓄力释放 155–157，245 对应真蓄力释放 146/189/190。145 与强蓄力起手源姿势位置 RMS 为 2.77 毫米，245 与真蓄力起手为 0.30 毫米；245 为 114 帧、末帧 113 稳持，保留原身体与手腕。按上一基础／强释放槽选择下一保持段；0／0.65／1.25 秒仍为模组展示等级阈值，不称原 Focus 或游戏判定。

完整自动演示使用九组连续「蓄力→释放」，依次覆盖一级的基础／强／真，再覆盖二级和三级的三阶段。只对蓄力按目标展示等级阈值加 0.12 秒、最低 0.25 秒决定自动松开；不强迫每次等待原保持循环的全长度。此时长与三档分组是模组编排策略，源保持和释放身体／手腕曲线仍取各自原条目，不作为怪猎原生精确蓄力时机认证。Shift 辅助纳刀与默认独有键仅在没有被自定义实际动作键占用时生效，自定义键绑定优先。
