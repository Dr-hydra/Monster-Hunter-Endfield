# 终末地 1.6.3 客户端适配记录

日期：2026-10-15。候选版本 `1.0.0-compat-1.6.3-rc1`；Windows x64，EML format 1 / Native ABI 1。本记录说明本地开发与离线验证结果；没有运行游戏，含游戏素材的候选包不随源码发布。历史 `combat-rc2` 记录保留为旧基线，不代替本轮证据。

## 当前资源来源

- 当前客户端为 1.6.3，GameAssembly 为 320,407,528 字节，metadata 为 74,424,564 字节；IL2CPP metadata v29。以当前文件直接提取的元数据核对方法，不复用旧 RVA。
- 有效资源按 `StreamingAssets` → `Persistent` 覆盖。1.5.3 与 1.6.3 的 manifest GUID 可能相同，不能用 GUID 相同证明资源或客户端等价。
- 可玩角色由 33 增至 34，新增 `chr_0036_jsspsi`（祀，双手剑）；占位角色不列为支持角色。目录中的 minghe 系列形态未进入可玩角色表，不据此宣布支持。
- 普通装备由 80 增至 84，新增 `wpn_claym_0018`、`wpn_claym_0019`、`wpn_sword_0021_ink`、`wpn_sword_0024`。加上两件独立特殊模型，目录共 86 条。
- 角色索引 `current_source` 同时记录版本、覆盖顺序、当前角色/装备 ID 集合与本地证据路径。逐份源等价复核、实际几何检查与实机验证分开记录；资源元数据和必要适配配置进入源码，大型源文件、解码结果和运行包仍留本地。

## 客户端修正

1. 主表 64 个方法在当前元数据中均可唯一匹配。TailLateTick 不再通过 wildcard 接受同名同参数个数的不同类型方法；原生 detour 检查实例/静态与 abstract 标志，每轮解析清除旧结果。
2. RaycastHit 从真实值类型大小、装箱头和字段偏移构造布局，核对 Vector3 大小与字段、对齐、重叠和边界；未知布局不调用物理查询。地形委托核对完整签名，状态提供 `terrain_layout_verified`。所需新增 IL2CPP 导出均已在当前 DLL 中确认存在。
3. 配置版本仅接受缺省或整数 1/2；按键拒绝小数、溢出及保留值。旧配置迁移和自定义键位保留，网页与原生端校验对齐。
4. 注册表和目录按当前角色/装备 ID 集合核对，去掉 33/80/82 的固定上限，同时拒绝缺失来源、重复 ID、缺项和错 profile 引用。网页离线名单增加祀，浏览器检查读取当前注册集合。
5. CMake 从 `module.json` 嵌入 DLL 构建身份。打包检查模块 ID、版本和元数据，拒绝旧 DLL 混入新包。此检查不运行 DLL，也不计算文件哈希。
6. 新构建目录的 CTest 自动准备运行资源银行，再执行 packed_tracks 精确回读，不依赖旧构建留下的银行文件。

## 资源重建与验证范围

`tools/refresh_endfield_profile_inputs.py` 从指定当前输入和有效 VFS 重新取得角色/装备闭包；`tools/verify_resource_overlay.py` 保存直接资源核对证据。`tools/endfield_profiles.py` 必须明确指定版本、输入根目录、对象图和 overlay 报告，禁止无参数静默使用旧 1.5.3 缓存。

完整重建命令、当前表来源和保留的解码告警见 [资源适配记录](client-1.6.3-resources.md)。

增量报告区分注册总数与本次实际验证数。旧校准只在完整骨路径、bind/挂点及所需几何等价或重新验证后保留；新增角色使用自己的真实骨架、手指和脚底数据。参考图片只是离线检查证据，不能作为游戏中的材质、布料或手感通过证明。

本轮普通角色网格覆盖 204 项，36 项按当前资源重扫、168 项通过完整输入等价核对复用，数值错误为 0。特殊模型覆盖 68 项，12 项重扫、56 项等价复用，数值错误为 0；祀火刀 298 个实际采样帧、弓 99 个实际采样帧通过。太刀两套模型的接触数据覆盖全部 34 角色与 20 核心槽。

最终代码在新构建目录通过 23 项 CTest（22 项原生检查及 1 项银行准备 fixture）；打包器 22 项检查通过。产品目录为 6 模式、34 角色、86 模型、196 音源，204 个角色模式均有参考图，动作、声音和源预览缺项为 0。包导入与浏览器运行记录由各自验证工具保存在本地目录；宿主初始化成功不能解释为游戏内验证通过。

## 尚未闭环

- 当前游戏中的材质、特效、布料、换装/切场景恢复、地形接地、镜头、输入同步、GPU/内存与帧预算仍需实机验收。`runtime_verified` 与 `visual_quality_certified` 保持 false。
- 方法可解析、存在 native 入口或静态直接调用证据，不等于所有运行时路径都经过 Hook。虚调用、内联与热补丁覆盖仍需运行时观察。
- 原怪猎的完整伤害公式、箭群横向分布/逐箭挂点、部分原控制器帧窗、RTPC/混响和特殊模型完整材质时序仍保留既有实现边界，未因本次版本适配而宣称补齐。
- 解码器的非关键纹理或未知类型警告按角色保留在本地来源报告中；骨架/几何通过不能消除这些显示层未知项。

本地原始证据位于 `output/version-update/`、`output/hook-update/` 与 `research/client-update-1.6.3/`；这些目录不作为安装包运行依赖，也不随源码分发。
