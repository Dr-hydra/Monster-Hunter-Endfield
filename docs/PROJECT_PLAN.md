# Monster Hunter Endfield 项目计划

更新：2026-10-15。当前开发版本 `1.0.0-compat-1.6.3-rc2` 面向终末地 1.6.3，适配基线见 [版本记录](implementation/client-1.6.3.md)，本轮修复见 [rc2 缺口处理](implementation/client-1.6.3-rc2.md)；正式 1.0 仍需游戏内验收。历史离线结果见 [战斗候选版记录](implementation/combat-rc2.md) 和 [offline-rc1](implementation/offline-rc1.md)。

## 成品范围

Windows x64 原生 EML 模块，保留 format 1 / ABI 1 和 `endfield.longsword.showcase` 模块 ID。覆盖太刀、片手剑、大剑、长枪、轻弩、弓，支持版本内 34 个角色、84 件普通装备和两把特殊展示模型。单手剑对应太刀／片手剑，双手剑对应大剑，长柄对应长枪，手铳对应轻弩，施术单元通过独立弓展示。

六模式包含手动输入、派生、自动演示、独立展示武器、统一 PCM、网页工坊、游戏 HUD 与本地练习。莱万汀太刀及提夫罗斯弓是重点组合，两把模型分别限太刀和弓模式，并可跨角色展示。提夫罗斯在本地角色表名为“提弗洛斯”，ID 为 `chr_0034_typhoea`。

动作及操作以《世界／冰原》原版为基准；历史 Rise／Valor 条目保留来源标记，不混入原版还原验收。操虫棍、铳枪等其他模式可另行扩展。本地练习只维护模拟 HP 与反馈，不发送战斗数据，不修改真实伤害、奖励、存档或服务端；核心功能无本地服务端依赖。

角色与武器分别适配：人体 profile 保存主蒙皮识别、完整骨路径、体型、手指和鞋底；武器 profile 保存资源／形态、安装变换、握柄和附属部件。挂点同名不等于安装矩阵相同。原装备只开放适用模式，不要求把 84 件原装备强套六类动作。

## 来源与验证流程

有效版本索引 → 定向导出 → 坐标／依赖审计 → 源猎人与源武器复现 → 实际目标网格预览 → 烘焙 → 原生和 EML 离线验证 → 游戏内检查。

终末地角色材料优先使用离线 VFS、对象图和真实蒙皮；源猎人需核对槽位、父级上下文、有效帧和控制轨道。主人体按 SMR palette 与完整路径选择，排除士兵、分身和武器子骨架。手腕、剑轴及挂载由资源或实测证据确定，不能按预期外观猜旋转。

派生资源保留客户端／manifest、源路径／ID、覆盖来源、工具版本、骨骼映射、帧范围和未知项。模型、手指、鞋底和实际武器共同参与检查；静态骨线或近似碰撞不能证明完整布料和场景效果。源码仓库不携带原游戏素材，工具与本地依赖条件见 [素材重建](RESOURCE_REBUILD.md)。

## 正式 1.0 验收要求

1. 六模式的核心招式、派生、手动操作和完整演示均有可追溯来源，展示策略与未核定原行为明确区分。
2. 支持名单、普通装备适用范围及特殊模型配置与目标客户端一致；代表体型、挂载和 LOD 分支完成游戏内抽验，不把离线全覆盖写成逐项实机通过。
3. 双手握持、脚底接地和显示位移稳定；平地、坡面、台阶、墙面、低顶及镜头检查通过，不写真实实体位置。
4. 特殊模型、声音、箭弹和 HUD 同步；暂停、取消、静音、失焦及切换不留下过期声音或道具。
5. 退出、换人、换装／模型池化、切场景和卸载统一清理输入、PCM、特效、箭弹、资源句柄，恢复原姿势与装备显示；异步结果不能复活旧对象。
6. 网页草稿、已保存和宿主已应用状态可区分；预设迁移、冲突、错误反馈、键盘导航、小窗口及高 DPI 检查通过。
7. 在明确记录的客户端和硬件上测量加载峰值、内存、CPU、GPU及音频／箭弹并发，设定并达到性能预算；长时操作无持续资源增长。
8. 完整包通过路径、轨道、来源、限额、负向输入及真实 EML 生命周期检查；离线、宿主和游戏内证据分别留档。
