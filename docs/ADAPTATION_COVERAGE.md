## 4. 验收批次

1. **两个专项**：莱万汀太刀、提夫罗斯弓的全核心动作/演示、前后侧镜头与声音；女管理员宏愿为回归对照。
2. **体型样本**：男女管理员、莱万汀、提夫罗斯、黎风、狼卫、骏卫、大潘，按实际比例分组，不按性别推断骨架相同。
3. **全名单**：204 组合全核心动作离线求值、带网格预览与接触/地面异常扫描；默认模式人工复核，跨类至少复核异常和招牌动作；两个特殊武器另验跨角色部件操作。
4. **装备形态**：逐项适用模式、独立模型切换、原显隐/恢复；同网格不同装配不能省略。
5. **末端抽验**：按体型、挂载/材质/LOD 分支、场景和 HUD 布局选实机样本；一个样本失败时扩大同分支检查。EML OfflineHost 负责能离线证明的初始化、配置与恢复。

记录源槽/帧、角色/武器、镜头、修前修后、实际声音、误差和剩余项。柄位距离、方向、脚底间隙等容差先依据源/目标尺度和确认样片定标，再锁为回归门槛，不给所有体型拍脑袋套统一厘米/角度。

工具导出成功、数值有限、骨架能动只是前置检查；实际网格姿态、附属表现、HUD/声音反馈与清理单列。原生 shader 或衣物动态未运行验证时明示，正式版不得存在未解释的缺图、核心动作缺项或未完成 P0。

## 5. 当前离线证据与边界

以下研究报告包含本地游戏派生数据，保存在忽略目录，不随源码仓库分发。

1.6.3 复核按当前有效 VFS 重新选择依赖闭包，未使用旧 GUID 当作版本一致证明（两版本的 manifest Version 字段相同）。角色、装备与中文文本三表均重新从 Persistent 解码并与本轮输入完整比对。34 角色逐份重新读取骨架和实际网格：28 个旧角色的骨架、挂点和完整几何 payload 与历史输入精确相等；女管理员有极小绑定/挂点浮点变化，昼雪、黎风、别礼、汤汤有绑定或网格变化，另新增祀。这六名角色的六模式共 36 项重新扫描，其余 168 项凭实际输入等价保留；太刀六项在发布新接触 mask 后再次扫描。特殊模型 12 项重新扫描、56 项按同样证据复用，总计 68 项。两把特殊模型的当前骨架/renderer 与 3＋2 个实际 LOD0 网格也已逐项比对相等。

本轮接触 gate 为两模型 × 34 角色 × 20 源候选槽；新增和变更六角色均重新计算，没有空白 mask。昼雪历史追加鞋底顶点在当前 mesh 中按位置、四权重及骨索引完全匹配后才保留。完整证据位于 `research/client-update-1.6.3/` 下的 `rig-comparison.json`、`geometry-comparison.json`、`foot-probe-migration.json`、`special-comparison.json`、`contact-special-validation.json` 和本轮验证记录。

资源后端仍有明确缺口：安塔尔、洛茜、庄方宜和装备共同依赖中的默认 MRO 纹理读取告警；诀的一条未知 ClassID 告警。主骨架、目标 renderer/mesh、palette 和实际顶点已分别核验，但不宣称整个依赖闭包无解析告警。上述提示保留在 source graph、生成日志及 profile evidence。原生材质、cloth/spring 和运行时行为仍需游戏内验证。
