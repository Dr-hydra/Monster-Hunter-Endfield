# 角色与展示武器配置

此目录分别保存角色人体和展示武器配置。当前名单为 34 个角色、84 件普通装备和两把特殊展示模型；六模式的适用范围与验证状态见 [覆盖表](../docs/ADAPTATION_COVERAGE.md)。

人体配置从主角色实际蒙皮和完整骨路径识别骨架，记录绑定姿势、体型、手指、脚底和挂点。武器配置独立记录资源／形态、安装变换、握柄、左右手支持与附属部件；挂点同名不能证明安装变换相同。

莱万汀长刀限太刀，提夫罗斯弓限弓；普通装备按各型号的适用模式使用，独立模型提供跨类别展示。配置不包含原模型素材，也不代表动态装配或最终游戏外观已通过验收。客户端更新后需重新核对源对象图和配置，不能直接继承旧版本的验证状态。

版本更新以 `index.json.current_source` 的游戏版本、有效 VFS 覆盖顺序和角色／装备 ID 集合为准。manifest GUID 可能跨版本复用，不能单独证明当前资源。来源等价复核、离线网格检查和实机验证分别记录，旧校准仅在当前骨架等价或重新验证后保留。
