# 本地运行资源

此目录保存运行所需的游戏派生素材，除本说明外不纳入 Git。公开源码不包含原版游戏文件、动作烘焙、模型、纹理、PCM 或大型预览，新克隆不能直接生成完整安装包。

`1.0.0-combat-rc2` 的本地资源覆盖六模式、1185 个可加载身体动作槽、源骨架／武器／手指／握持／接地轨道，以及 196 条 PCM（188 条模式音源＋8 条特殊模型原声）。动作槽包含上下文、合成和带来源标记的历史条目，不等于招式数。

重建前需准备匹配版本的合法游戏输入、对应提取工具及对象图；部分研究脚本还依赖本地工具和既有缓存。流程与限制见 [素材重建](../docs/RESOURCE_REBUILD.md)，包依赖见 [开发与构建](../docs/DEVELOPMENT.md)。资源完整和离线验证通过不表示游戏内外观已验收。
